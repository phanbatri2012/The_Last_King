# Phase 0 acceptance criteria

Phase 0 is complete when:

1. the repository is initialized and project rules are present;
2. Godot can import the project without script or resource errors;
3. the Bootstrap scene initializes global services and opens the placeholder main menu;
4. the platform adapter boundary works on desktop and Web;
5. English and Vietnamese localization data load with English fallback;
6. faction roster data validates and includes both United States and Persia entries;
7. headless automated smoke tests pass;
8. Windows and Web release exports are produced and inspected for basic size constraints.

Phase 0 does not include player movement, combat, enemies, XP, upgrades, summoning, or final art.
